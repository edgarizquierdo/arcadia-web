Política de privacidad

Cómo tratamos los datos personales cuando contactas con Arcadia Global Analytics.

2. Datos que podemos tratar

Cuando contactas con nosotros podemos tratar los datos que facilites voluntariamente, como nombre, empresa, dirección de correo electrónico, información incluida en tu mensaje y cualquier otro dato necesario para atender tu solicitud. El formulario de contacto de esta web abre el cliente de correo del usuario y no almacena por sí mismo los datos en una base de datos del sitio web.

3. Finalidades

Utilizamos los datos para responder consultas, preparar información o propuestas solicitadas, gestionar actuaciones precontractuales o contractuales, mantener las comunicaciones necesarias con clientes y potenciales clientes y cumplir obligaciones legales vinculadas a nuestra actividad.

4. Base jurídica

La base jurídica será, según el caso, tu consentimiento al contactar con nosotros, la aplicación de medidas precontractuales solicitadas por ti, la ejecución de una relación contractual o el cumplimiento de obligaciones legales. Cuando corresponda, determinadas comunicaciones estrictamente vinculadas a una relación profesional existente podrán apoyarse en el interés legítimo de mantener dicha relación.

5. Conservación

Los datos se conservarán durante el tiempo necesario para atender la solicitud y gestionar la relación que pueda derivarse de ella. Posteriormente podrán mantenerse bloqueados durante los plazos exigidos por la normativa aplicable para atender posibles responsabilidades.

6. Destinatarios

No vendemos datos personales. Podrán acceder a ellos proveedores que nos presten servicios necesarios para la actividad, actuando bajo las garantías contractuales exigibles, así como administraciones, organismos o autoridades cuando exista una obligación legal.

7. Transferencias internacionales

Arcadia no prevé realizar transferencias internacionales de datos derivadas directamente de este formulario. Si para un servicio concreto fuese necesario utilizar proveedores ubicados fuera del Espacio Económico Europeo, se aplicarán las garantías exigidas por la normativa de protección de datos.

8. Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad cuando proceda, así como retirar un consentimiento previamente otorgado. Para ejercerlos, escribe a arcadia@arcadiaclimatic.com indicando el derecho que deseas ejercer y aportando la información necesaria para verificar tu identidad cuando resulte imprescindible.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos si consideras que el tratamiento de tus datos no se ajusta a la normativa aplicable.

9. Decisiones automatizadas

No utilizamos los datos recibidos a través de la web para adoptar decisiones automatizadas con efectos jurídicos o significativamente similares sobre las personas.

10. Seguridad y cambios

Aplicamos medidas razonables orientadas a proteger la información frente a accesos, alteraciones, pérdidas o usos no autorizados. Esta política podrá actualizarse cuando cambien nuestros tratamientos, servicios o requisitos legales.
